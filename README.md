# Personal Portfolio Website

This is the source code for my personal portfolio website.

## Tech Stack
- HTML
- CSS (Inline & External)
- Bootstrap 5
- Vanilla JavaScript
- Hosted on Cloudflare Workers
- Source code stored on GitHub

## Design Guidelines & Constraints
**Important:** Do not redesign the existing style unless explicitly asked. Preserve the current visual style and existing working interactions. Keep the code clean and responsive.

### Core Design Elements
- Glassmorphism navbar
- Gradient pastel background
- Magnetic hover on navbar items
- Work dropdown opens on hover
- Responsive mobile navbar
- Portfolio hero
- "What I Do" section
- "Creative Tools" section
- "AI & Creative Tools" section

### Navigation Structure
**Navbar Order:**
